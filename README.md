CRM Fácil — MVP 0.1

Este é um protótipo funcional de interface do CRM.
- Funciona no celular e computador.
- Possui Início, Clientes, Negócios e Tarefas.
- Permite cadastrar clientes.
- Salva os dados no navegador usando localStorage.

IMPORTANTE:
Este MVP ainda NÃO possui login, banco de dados online, pagamentos ou sincronização entre dispositivos.
A próxima etapa é transformar este protótipo em um SaaS real com banco de dados, autenticação e assinatura.
